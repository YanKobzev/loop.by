# loop.by — первая версия
Светлый сервисный дизайн: фон #f6f7f2, текст #243328, вторичный #687066, акцент #d5ef87. Шрифт Arial с системными резервными гарнитурами, поддержка кириллицы без внешних запросов. Крупная спокойная типографика, предметные SVG-иллюстрации техники; это иллюстрации категорий, не изображения товаров в наличии. Первая сцена: заголовок о второй жизни техники и выбор категории. На мобильном категории в две колонки. Контент: последовательность оценки, условия сохранения цены, FAQ. Движение только для обратной связи; reduced-motion поддерживается.
