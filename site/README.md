# loop.by — выкуп техники, версия 1

Node.js 24 и npm. Из каталога `site/`:

```
npm ci
npm run dev
npm run lint
npm run build
npm run start -- --hostname 0.0.0.0
```

На hoster.by необходим тариф с Node.js и постоянно работающим процессом либо VPS, HTTPS reverse proxy и доступом к базе/Telegram. Тип текущего тарифа ещё не установлен. На обычный статический/PHP-хостинг эту серверную часть скопировать нельзя. Домен и старый Tilda-сайт пока не менялись.

## Статус

Готовы адаптивная страница, SVG-иллюстрации категорий, четыре шага анкеты, условные вопросы, проверка ввода и обработчик сохранения заявки через REST API Supabase. Пока переменные не настроены, сервер возвращает 503; форма сохраняет ответы в памяти открытой страницы и НЕ изображает успешную отправку. Перезагрузка очищает ответы.

## До реальных заявок

- Уточнить тариф hoster.by и серверный вариант размещения.
- Выполнить `../supabase/leads.sql` в выбранной базе Supabase. Таблица закрыта RLS, доступ только серверу.
- Создать Telegram-бота через BotFather, добавить в рабочий чат. Секреты вне Git: `.env.local` или защищённые настройки сервера. Имена — `.env.example`.
- В текущем API реализована первая попытка уведомления. Неприсланные уведомления сохраняют статус pending; автоматический worker повторных попыток ещё НЕ реализован.
- Подключить ограничение частоты запросов с постоянным хранилищем, защиту от повторной отправки и логирование без персональных данных.
- Подключить хранилище фото и проверку загрузок.
- Реализовать защищённые команды сотрудника для оценки, страницу результата и добровольное подключение Telegram клиента через одноразовый Start-токен. Сейчас они НЕ реализованы; контакт поступает сотруднику для ручного ответа.
- Заполнить реквизиты, контакты, политику обработки данных и срок хранения; `/privacy` пока черновик.
- Добавить SEO-адреса и OG-изображение после определения адреса запуска. Пока metadata запрещает индексацию тестовой версии.
- Выполнить проверку реальной заявки: запись в базе, Telegram сотрудника, назначение оценки, получение клиентом. Без настроенных интеграций это не проверено.

Не отправлять реальные данные в тестовую версию. Ключи не передавать в чат и не коммитить.
